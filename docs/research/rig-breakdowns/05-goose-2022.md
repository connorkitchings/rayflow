## Summer 2022 — Dripfield Tour

### Era Context
Goose's breakthrough year. First time playing venues like Red Rocks and Radio City Music Hall. First time with a consistent tour design across all venues. First time incorporating cue-stacked songs (16) alongside traditional busking.

### Programming Evolution
- **Previously (2018-2021):** 100% punted (busked). No pre-programmed cues.
- **Summer 2022:** 16 songs cue-stacked for composed sections; rest punted "jam band style." First hybrid show file.
- **Collaboration:** Tony Caporale joined to program cue stacks: "I wanted to integrate more structure on the lighting for the composed parts of the songs."
- **No timecode.** Caporale: "There is definitely no timecode in this show which is a nice change for me."

### Verified Fixture Inventory

| Fixture | Count | Position | Notes |
|---------|-------|----------|-------|
| Robe Tetra2 | 16 | Floor upstage, pipe-and-base stands at 20° angle | Moving LED battens. "Integral part of the floor package." Stands built by tech Danny McDonald (master welder). |
| Chauvet Color STRIKE M | 18 | 6 each on upstage, midstage, and downstage truss, at 20° angle | Motorized strobe/washes. Run in 96 channel mode. Sometimes the rig's only light source. "As bright as it gets." |
| Additional moving heads | Not specified | Overhead trusses | Primary spots and washes not named in these articles |

**Vendor:** Main Light (principal lighting vendor)
**Pre-viz:** Capture (Goedde and Caporale pre-vizzed all songs in Nashville)
**Rehearsal:** 3 days production rehearsals in Pod 2 at Rock Lititz
**Console:** grandMA3

### Key Goedde Quotes
- On Color STRIKE M: "They're as bright as it gets. We use them in 96 channel mode and create some great, unique looks when we pixel map the face."
- On Tetra2s: "There's no other batten that has that amazing zoom and we do some crazy stuff with it. We have some very cool 'digital symmetry' looks with opposite angles."
- On FORTES (winter 2022): "I had to keep the intensity down as they really punch through."
- On Robe: "When I know there's Robe on the rig, I know it's rock-solid."

### Key Caporale Quotes
- "Andrew and I wanted to develop a hybrid style of show file. The idea is to be able to make customized looks and details for the core components of the songs. Then, when the band heads into a jam, Andrew busks."
- "We have a very balanced show file. There is definitely no timecode."
- On Color STRIKE M: "There are cool moments when we are using just the Strike M's, whether it's for a blinder look, or for the pixley goodness."
- "I think our communication and trust has been a very big factor in the success of this show."

## Distinguishing Features

- **2022 was a transitional year:** Goose went from 100% punted to 16 cue-stacked songs + punted jams. This hybrid approach mirrors Waful's UM model.
- **Goedde-Caporale collaboration:** The LD/programmer partnership. Goedde provides creative direction and band rapport; Caporale provides cue-stacking expertise and programming depth. This is the Kuroda/Giffin pattern scaled down.
- **Consistency achieved:** "For the first time ever with Goose, we have the luxury of having the same tour design for almost all venues."
- **The Tetra2 as signature:** The 20° angled Tetra2 stands became a defining visual element of the Dripfield tour. Custom-built by the lighting tech. The "digital symmetry" looks became a Goose signature.
- **Color STRIKE M as workhorse:** 18 units in 96 channel mode. Sometimes the only light source. Used for both blinder hits and pixel-mapped effects.
- **Pre-viz commitment:** 3 days at Rock Lititz + Capture pre-viz in Nashville. Professional-grade preparation for a band that was still on its way up.

## RayFlow Relevance

1. **The "first cue-stacked songs" moment:** Goose's transition from 100% punted to hybrid mirrors what RayFlow enables — taking an amateur who has never programmed cues and giving them 16 cue-stacked songs. This is exactly the user journey.
2. **LD + programmer partnership:** Goedde + Caporale = user + AI. The user provides band knowledge and taste; the AI provides programming depth and cue-stacking expertise.
3. **Custom fixture stands as creative differentiator:** Danny McDonald's welded Tetra2 stands created a signature look. RayFlow should support custom fixture positioning (angles, offsets) as a creative parameter.
4. **Consistency unlocks depth:** "For the first time ever... the same tour design for almost all venues." A stable rig enables deeper programming. RayFlow's rig templates enable this consistency.
